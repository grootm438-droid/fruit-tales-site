# Privacy Policy — Fruit Tales Uploader

Last updated: November 1, 2026

**Fruit Tales Uploader** is a private tool used only by the owner of the "حكايات الفواكه / Fruit Tales" YouTube channel to upload the channel's own videos.

## What the app accesses
- It uses the YouTube Data API, with the channel owner's permission, only to upload videos, set their titles, descriptions, thumbnails and publish schedule on the owner's own channel.

## What the app does not do
- It does not collect, store, sell or share personal data of any viewer or other user.
- It does not read comments, subscriber lists or any data of other accounts.
- It is not offered to the public; the only user is the channel owner.

## Data storage
- The only stored credential is the owner's OAuth refresh token, kept encrypted as a GitHub Actions secret, and used solely for uploading. The owner can revoke it at any time at https://myaccount.google.com/permissions.

## Google API Services
The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
